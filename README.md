# 🐍 Snake Water Gun Game | Python

A simple and fun **Snake Water Gun game built using Python** where you play against the computer!

This beginner-friendly project demonstrates Python fundamentals, including the `random` module, dictionaries, user input, and conditional statements.

## 🎮 About the Project

Snake Water Gun is a classic hand game similar to Rock Paper Scissors.

The computer randomly chooses Snake, Water, or Gun. The player enters their choice, and the program determines the result.

### 🏆 Game Rules

- 🐍 Snake beats Water.
- 💧 Water beats Gun.
- 🔫 Gun beats Snake.
- 🤝 If both choose the same option, the game is a draw.

## ✨ Features

- Random computer choices
- Simple command-line interface
- User-friendly input options
- Automatic win, lose, and draw detection
- Beginner-friendly Python logic

## 🛠️ Technologies Used

- **Language:** Python
- **Module:** `random`
- **Concepts:** Dictionaries, user input, conditional statements, and f-strings

## 🚀 Getting Started

### 1. Install Python

Download Python from the official website:

https://www.python.org/downloads/

### 2. Clone the Repository

```bash
git clone https://github.com/YOUR-USERNAME/snake-water-gun-game.git
```

Replace `YOUR-USERNAME` with your GitHub username.

### 3. Open the Project Folder

```bash
cd snake-water-gun-game
```

### 4. Run the Game

```bash
python snake_water_gun.py
```

If your system uses the Python launcher, you can also try:

```bash
py snake_water_gun.py
```

## 🕹️ How to Play

Enter one of the following choices when prompted:

| Input | Choice |
|---|---|
| `s` | Snake |
| `w` | Water |
| `g` | Gun |

The computer will randomly select its choice, and the program will display the result.

## 💻 Sample Output

```text
Enter your choice: g
User choose Gun
Computer choose Water
You win!
```

*Note: The computer's choice is random, so your output may differ each time.*
